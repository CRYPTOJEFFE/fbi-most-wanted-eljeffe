RESEARCH WITH CONTEXT

The workbench guide.

A local workspace for exploring public records with their provenance intact.

01 / START

Connect or import

Sync the FBI Wanted API or an OpenSanctions dataset in Data sources. You can also import line-delimited FollowTheMoney JSON. Use the fictional demo to explore without downloading live data.

02 / INVESTIGATE

Follow the source

Search names, aliases or identifiers, then open a record to inspect its properties, source links and declared relationships. Similar names do not establish identity. Related entities are source-declared references, not inferred matches.

03 / TAKE IT WITH YOU

Export with provenance

Export the current search as a ZIP containing FollowTheMoney JSONL and a provenance manifest with a checksum. If sources share an entity ID, select one source before export. Historical records remain searchable but are excluded from snapshot exports.

04 / UNDERSTAND STATUS

Different records. Different meanings.

Wanted notices, missing-person notices, sanctions designations and politically exposed person records are separate categories. PEP status does not imply wrongdoing. “Current” describes local snapshot membership, not a legal determination.

Local by default

The workbench runs on your machine. Syncing contacts the selected public data provider; downloading record files contacts supported official source hosts. Records are kept in your local workspace. This interface does not automatically refresh sources or send your searches to a third-party service.

For a large OpenSanctions collection, the CLI offers a more direct way to sync and export. Run eljeffe --help or python -m eljeffe --help in your terminal.
